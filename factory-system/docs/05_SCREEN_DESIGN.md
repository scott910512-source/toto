# 5. 화면 설계서

테마: **리퀴드 글라스(Liquid Glass)** — Apple iOS 스타일의 반투명 유리 패널,
backdrop-blur, 둥근 모서리(2xl), 그라데이션 배경, SF Pro 폰트 스택.

## 5.1 공통 레이아웃

```
┌──────────────────────────────────────────────┐
│ [사이드바]        [상단바: 제목 · 테마 · 사용자 · 로그아웃] │
│  - 대시보드      ┌────────────────────────────┐ │
│  - 생산 정보     │                            │ │
│  - 설비 점검     │      페이지 콘텐츠            │ │
│  - 품질 데이터    │   (글라스 카드 + 차트/테이블)    │ │
│  - 안전 데이터    │                            │ │
│  - AI 검색       │                            │ │
│  - 사용자 관리    │                            │ │
│  - 설정 · 백업    └────────────────────────────┘ │
└──────────────────────────────────────────────┘
- 모바일: 사이드바는 햄버거 메뉴로 슬라이드 인
```

## 5.2 화면 목록

| # | 화면 | 경로 | 주요 요소 |
|---|------|------|-----------|
| 1 | 로그인 | `/login` | 글라스 카드, 데모 계정 안내 |
| 2 | 대시보드 | `/` | KPI 6카드, 추이/막대/스택 차트 |
| 3 | 생산 정보 | `/production` | 검색·필터, 테이블, 입력 모달, Export |
| 4 | 설비 점검 | `/equipment` | PASS/FAIL 뱃지, 필터, CRUD |
| 5 | 품질 데이터 | `/quality` | OK/NG 뱃지, 규격범위 표시 |
| 6 | 안전 데이터 | `/safety` | 완료/미완료 뱃지, 체크박스 |
| 7 | AI 검색 | `/ai` | 자연어 입력, 예시 칩, 답변+표 |
| 8 | 사용자 관리 | `/users` | 권한 뱃지, 계정 CRUD (admin) |
| 9 | 설정·백업 | `/settings` | 테마, 백업/복원, 시드 |

## 5.3 대시보드 KPI 카드

| 카드 | 지표 | 색상 |
|------|------|------|
| 일일 생산량 | 오늘 합계 | iOS Blue |
| 월 생산량 | 당월 합계 | Indigo |
| 평균 수율 | 당월 평균 % | Green |
| 설비 이상 | FAIL 건수 | Orange |
| 품질 부적합 | NG 건수 | Red |
| 안전 미완료 | 미완료 건수 | Purple |

## 5.4 데이터 관리 화면 공통 UX

- 상단: 제목 + Export 버튼(Excel/CSV/PDF) + [추가]
- 필터 바: 통합 검색 + 카테고리별 드롭다운 + 날짜 + [검색]
- 테이블: 정렬/페이지네이션, 행 hover, 행별 [수정]/[삭제]
- 입력/수정: 글라스 모달, 필드 타입별 입력(텍스트/숫자/일시/선택/체크박스)
- 권한: `viewer` 는 조회만(추가/수정/삭제 버튼 숨김)

## 5.5 반응형 · 테마

- **Breakpoint**: `lg(1024px)` 기준 데스크톱/모바일 분기
- **다크모드**: 우측 상단 토글, `prefers-color-scheme` 초기값, localStorage 영속
- **터치**: 버튼 최소 높이 42px, 카드 간격 충분히 확보
