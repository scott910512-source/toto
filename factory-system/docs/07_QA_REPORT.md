## 7.2 발견 → 즉시 수정한 버그 (8건)

| # | 심각도 | 증상 | 조치 |
|---|--------|------|------|
| 1 | 🔴 높음 | **PDF Export 시 한글이 빈칸**으로 출력(기본 Helvetica 폰트) | ReportLab 에 한글 폰트(Nanum) 등록, Docker 이미지에 `fonts-nanum` 설치 |
| 2 | 🔴 높음 | **마지막/본인 관리자 계정 삭제 가능 → 시스템 잠김**(테스트 중 실제로 admin 삭제되어 로그인 불가 발생) | 본인 삭제 금지 + 마지막 활성 관리자 삭제·강등·비활성화 차단 |
| 3 | 🟠 중간 | **음수 생산량** 입력 허용(-500 수용) | 수량 `≥0` 서버 검증(422) |
| 4 | 🟠 중간 | **수율 0~100 범위 검증 없음**(250% 수용) | 수율 `0~100` 서버 검증(422) |
| 5 | 🟠 중간 | **빈 LOT/공정/설비명** 등 핵심 식별자 공백 허용 | 핵심 필드 `min_length` + 공백 trim 검증(422) |
| 6 | 🟠 중간 | **품질 규격 하한 > 상한** 모순 입력 허용 | 하한 ≤ 상한 모델 검증(422) |
| 7 | 🟠 중간 | **품질 결과(OK/NG) 수기 입력** → 측정값이 규격 벗어나도 OK 저장 가능 | 측정값·규격으로 **서버가 자동 판정**(입력값 무시) |
| 8 | 🟡 낮음 | AI "생산량 추세"가 **PostgreSQL 전용 함수(to_char)** 사용 → SQLite/일부 환경 500 | DB 무관하게 Python 집계로 변경 |

> 위 8건은 모두 코드 수정 + 재테스트로 **해결 확인** 완료.

## 7.3 개선 권장 백로그 (사용자 불편 / 향후 기능)

우선순위: 🔺상 / ▪중 / ▫하

### 데이터 입력·관리
- 🔺 **엑셀/CSV 업로드 대량입력** — 현장은 엑셀로 관리하다 올리는 경우가 많음. 현재는 1건씩 또는 JSON 백업 복원만 가능. (양식 다운로드 → 업로드 → 검증/미리보기 → 적재)
- ▪ **데이터 화면에 날짜 범위 필터 UI** 추가 — 백엔드는 `date_from/date_to` 지원하나 화면에 입력칸이 없음.
- ▪ **품질 입력 폼에서 결과 자동 표시** — 서버는 자동 판정하지만, 폼의 OK/NG 드롭다운이 남아 있어 혼란. 측정값·규격 입력 시 결과를 자동 계산·읽기전용으로.
- ▪ **설비 점검 자동 판정** — 현재 기준값이 자유 텍스트("90 ~ 110")라 자동 PASS/FAIL 불가. 기준 상/하한을 숫자 필드로 구조화하면 자동 판정 가능.
- ▫ 테이블 **헤더 클릭 정렬** — 백엔드 `sort` 지원하나 UI 미연결.
- ▫ **페이지 크기 선택**(15/50/100) — 현재 15 고정.

### Export·리포트
- ▪ **"현재 화면 조건 그대로 Export"** — 지금은 필터·검색과 무관하게 전체(또는 날짜만) 내보냄. 보던 조건(공정/설비/판정 등)을 그대로 반영 필요.
- ▫ **활동 이력 엑셀 Export** — 감사 자료 제출용.

### 보안·운영
- ▪ **로그인 화면 데모 비밀번호 기본 입력 제거**(운영 빌드) — 현재 admin/admin1234 가 미리 채워져 있음.
- ▪ **비밀번호 정책**(최소 길이·복잡도) 및 최초 로그인 시 변경 유도.
- ▫ **토큰 자동 갱신(refresh)** — 현재 24h 만료 시 재로그인 필요.
- ▫ **로그인 실패 횟수 제한 / 감사 로그에 로그인 이벤트** 기록.

### 사용성·접근성
- ▫ 저장 실패 시 `alert()` 대신 **인라인 토스트·필드별 오류** 표시.
- ▫ **모바일에서 큰 테이블** 가로 스크롤 → 카드형 보기 옵션.
- ▫ 활동 이력은 **앞으로의 작업부터** 기록(소급 없음) — 화면 안내문 추가.

## 7.4 전문 코드리뷰 2차 — 추가 결함 수정 (3건)

배포 전 프로그래머 관점 정밀 점검에서 발견·수정.

| # | 심각도 | 결함 | 조치 |
|---|--------|------|------|
| 9 | 🔴 높음 | **입력검증 제약이 출력(*Out) 스키마에도 적용** → 백업복원/과거 데이터가 정책을 위반하면 *조회 시 500* 발생 (재현 확인) | 검증을 `*Create/*Update` 로만 한정, `*Base/*Out` 은 무검증 직렬화. 회귀 테스트 추가 |
| 10 | 🟠 중간 | **일일/월 KPI 경계를 UTC 로 계산** → 한국 자정이 아닌 오전 9시에 '오늘' 이 바뀜(생산량 집계 오류) | `TIMEZONE`(기본 Asia/Seoul) 설정 추가, 현지 자정 기준 계산. `tzdata` 의존성 추가 |
| 11 | 🟡 낮음 | 검증 실패(422) 시 프론트가 **오류 객체를 그대로 표시**(\[object Object\]) | `extractError()` 로 사람이 읽는 메시지 변환(필드명: 사유) |

→ 재테스트: 자동화 **13건 통과**, 라이브 QA 시나리오 **0 이슈**, 프론트 빌드 정상.

## 7.5 종합 의견

이번에 발견된 **데이터 정합성·보안 관련 8건은 모두 수정**했습니다.
