Background

Playwright란

웹 브라우저를 코드로 자동 제어하는 Python 라이브러리. 화면 좌표가 아니라 브라우저 프로토콜로 제어하므로 안정적이다.

주요 용도

웹 자동화테스트 자동화 웹 크롤링사내 시스템(MES·ERP·그룹웨어) AI Agent 브라우저 제어

지원 브라우저

ChromiumGoogle Chrome Microsoft EdgeFirefoxWebKit
Goal

목표

“인터넷이 안 되는 내부망 PC에 Playwright를 설치해 사내 웹시스템을 자동화한다.”

폐쇄망에서는 pip install이 PyPI에 접속하지 못하고, 회사 SSL 인증서 때문에 인증 오류가 난다. 이를 우회하는 것이 핵심.

Walkthrough

설치 과정 (단계별)

실제로 부딪힌 오류와 해결책을 순서대로 기록한다.

1

Python 설치 확인

python --version → Python was not found. Python 3.11 설치 후 py --version → Python 3.11.

※ Windows에서는 py 런처가 안정적.

2

패키지 다운로드 시도 → SSL 오류

py -m pip download playwright -d playwright_pkg

SSL: CERTIFICATE_VERIFY_FAILED / self-signed certificate in certificate chain — 회사 SSL 가로채기(인증서) 때문에 PyPI 인증 실패.

3

SSL 우회 → 다운로드 성공

py -m pip download playwright -d playwright_pkg ^
  --trusted-host pypi.org ^
  --trusted-host files.pythonhosted.org

성공. 받은 파일 (의존성 포함):

playwright-1.60.0-py3-none-win_amd64.whl · greenlet-3.5.2-cp311-win_amd64.whl · pyee-13.0.1-py3-none-any.whl · typing_extensions-4.15.0-py3-none-any.whl

4

오프라인 설치 (의존성 포함)

whl 하나만으론 안 되고 의존성도 함께 필요. 받은 폴더에서 인터넷 없이 설치:

cd playwright_pkg
py -m pip install --no-index --find-links=. playwright

Successfully installed greenlet · playwright · pyee

핵심 옵션 — --no-index(인터넷 안 봄) + --find-links=.(현재 폴더에서만 설치).

5

설치 확인

py -m pip show playwright   →   Version: 1.60.0

정상 설치.

6

Chromium 설치는 실패 — 하지만 불필요

py -m playwright install chromium
  →  SELF_SIGNED_CERT_IN_CHAIN (CDN 차단)

Playwright 전용 Chromium은 SSL 때문에 못 받는다. 그러나 받을 필요가 없다 — 이미 설치된 시스템 Google Chrome을 직접 가리켜 쓰면 된다.

Solution

시스템 Chrome으로 구동

Chromium 다운로드를 건너뛰고, 설치된 Chrome 실행파일 경로를 직접 지정한다.

경로 확인: C:\Program Files\Google\Chrome\Application\chrome.exe

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(
        executable_path=r"C:\Program Files\Google\Chrome\Application\chrome.exe",
        headless=True        # 창 없이 백그라운드 실행 (False면 창 표시)
    )
    page = browser.new_page()
    page.goto("http://내부사이트")
    print(page.title())
    browser.close()

💡 ModuleNotFoundError: No module named 'playwright' 가 뜬다면

설치는 됐는데 VS Code가 다른 Python 인터프리터를 쓰는 경우. 인터프리터를 설치한 Python 3.11로 맞추면 해결. (py -m pip show playwright로 설치 위치 확인)

Runtime

화면 잠금 상태 동작

Playwright는 화면 픽셀이 아니라 브라우저 프로토콜로 제어하므로, pyautogui와 달리 잠금 상태에서도 대부분 동작한다.

상태동작
모니터 꺼짐가능
화면 잠금 (Win+L)대부분 가능
로그오프불가
절전 모드불가

왜 중요한가

화면 좌표를 클릭하는 pyautogui는 잠금 상태에서 멈추지만, Playwright(headless)는 잠가둬도 데이터 수집·자동화가 돈다. 무인 자동화에 훨씬 유리하다.
