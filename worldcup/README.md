# ⚽ 사내 월드컵 스코어 예측 이벤트

직원들이 대한민국 경기 결과(스코어)를 예측하는 사내 이벤트 웹앱입니다.
HTML 링크로 접속해 사용하며, 사내 내부망에서 동작하도록 만들어졌습니다.

- 백엔드: **Node.js + Express**
- 데이터: **SQLite** (`better-sqlite3`)
- 엑셀: **xlsx 다운로드** (`exceljs`)
- UI: **Bootstrap 5** (로컬에 포함 — 인터넷 없이 동작), **모바일 대응**, **다크모드**

---

## 빠른 시작

```bash
cd worldcup
npm install
npm start          # 기본 포트 3000
```

브라우저에서 접속:
- 참여 화면: `http://<서버IP>:3000/`
- 관리자: `http://<서버IP>:3000/admin.html`

### 환경변수
| 변수 | 기본값 | 설명 |
|------|--------|------|
| `PORT` | `3000` | 서버 포트 |
| `ADMIN_PASSWORD` | `admin1234` | 관리자 비밀번호 (**운영 시 반드시 변경**) |

```bash
PORT=8080 ADMIN_PASSWORD='회사비번' npm start
```

DB 파일은 `worldcup/data/predictions.db` 에 자동 생성됩니다.

## 사용 흐름

### 직원 (참여자)
1. **최초 1회** 팀(부서)·이름 입력 → 이 브라우저에 저장됩니다.
2. 등록된 **대한민국 경기 카드** 목록에서 경기를 선택합니다.
   - 카드에 경기일시 · 마감(시작 시 자동) · **본인 제출 여부**(제출완료 ✓ / 미제출)가 표시됩니다.
3. 각 팀의 스코어를 입력하고 **예측 저장**.
4. 다시 들어가면 이미 제출한 예측이 보이며, **경기 시작 전까지** 수정할 수 있습니다.
5. 경기마다 따로 예측합니다(한 사람이 여러 경기 참여 가능).

### 관리자
`/admin.html` → 비밀번호 로그인 후:
- **전체 조회**: 팀·이름·경기·예측을 표로 확인(검색 가능)
- **경기별 통계**: 스코어별 인원수를 막대그래프로 확인
- **엑셀 다운로드**: 전체 예측 + 경기별 통계를 `xlsx`로 저장
- **경기 설정**: 경기 추가(상대팀·경기일시) / 삭제. 경기 시작 시각이 지나면 자동 마감됩니다.

## 핵심 규칙
1. 이름+팀은 최초 1회 입력(브라우저 저장)
2. 경기별로 예측 저장
3. 동일 경기 + 같은 "팀+이름" 조합은 **1건만** 제출 (DB UNIQUE 제약)
4. 경기 시작 전까지만 수정 가능 (시작 시각은 **KST** 기준 자동 마감)
5. 전체 조회 / 엑셀 다운로드는 관리자만 가능
6. SQLite 사용 · 모바일 대응 · 다크모드 · Bootstrap 기반

## 참고
- 경기일시는 한국 표준시(KST, +09:00) 기준으로 해석/마감합니다.
- 관리자 인증은 로그인 후 발급되는 토큰(8시간 유효)을 사용합니다.
- 내부망 전용 도구입니다. 외부 공개 시 `ADMIN_PASSWORD`를 반드시 강력하게 바꾸세요.
