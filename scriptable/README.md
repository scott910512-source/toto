# 📱 D-day 위젯 설치하기 (Scriptable)

아이폰·아이패드 홈화면에 **우리 아기 D-day**를 띄우는 방법입니다.
가족마다 아기가 다르니, **각자 자기 아기 날짜를 넣어서** 쓰면 됩니다.

준비물: 아이폰 또는 아이패드 · 5분

---

## 1단계 · Scriptable 앱 설치

App Store에서 **Scriptable** 검색 → 설치 (무료, 광고 없음)

> 만든 곳이 개인 개발자라 낯설 수 있는데, 애플이 직접 심사하는 정식 앱이고
> 위젯 만들 때 가장 많이 쓰는 앱입니다.

---

## 2단계 · 코드 붙여넣기

1. **Scriptable** 앱 열기
2. 오른쪽 위 **＋** 누르기
3. [`toto-dday.js`](toto-dday.js) 파일 내용을 **전부 복사**해서 붙여넣기
   - 아이패드에서 이 페이지를 열고 코드 영역을 꾹 눌러 **전체 선택 → 복사**
4. 왼쪽 위 **설정(⚙️) → Name** 에 `우리 아기 D-day` 입력 → **Done**

---

## 3단계 · 내 아기 날짜 넣기 ⭐

붙여넣은 코드에서 **맨 위 6줄만** 고치면 됩니다. 나머지는 건드리지 마세요.

```js
const BABY = {
  name: "또또",              // ← 우리 아기 이름(또는 태명)
  dueDate: "2026-12-14",    // ← 출산 예정일  (YYYY-MM-DD)
  birthDate: "",            // ← 아직 안 태어났으면 비워두세요
  appUrl: "https://scott910512-source.github.io/toto/app.html",
};
```

### 예시

**아직 임신 중이라면**
```js
name: "콩이",
dueDate: "2027-03-20",
birthDate: "",            // 비워둠
```
→ `D-174 · 임신 15주 2일` 이렇게 나옵니다.

**이미 태어났다면**
```js
name: "콩이",
dueDate: "2027-03-20",
birthDate: "2027-03-18",  // 실제 태어난 날
```
→ `D+45 · 생후 45일 · 6주 · 약 1개월` 이렇게 **자동으로 바뀝니다.**

> 나중에 아기가 태어나면 `birthDate` 한 줄만 채우면 됩니다.
> 코드를 다시 만들 필요 없습니다.

고쳤으면 오른쪽 위 **▶︎** 를 눌러보세요. 미리보기가 뜹니다.

---

## 4단계 · 홈화면에 올리기

> ⚠️ **꼭 홈화면에 올리세요.** 잠금화면 위젯은 iOS가 크기를 고정해서
> 아무리 해도 작게 나옵니다. 홈화면이 훨씬 큽니다.

1. **홈화면** 빈 곳을 **길게 누르기** (아이콘들이 흔들릴 때까지)
2. 왼쪽 위 **＋** 누르기
3. **Scriptable** 검색해서 선택
4. **좌우로 밀어서 크기 고르기** ← 여기가 중요합니다
   - 아이폰: **Large**(정사각 큰 것)
   - 아이패드: **가로로 아주 긴 것**(Extra Large)이 제일 큼
5. **위젯 추가** 누르기
6. 추가된 위젯을 **길게 누르기 → 위젯 편집**
   - **Script** → `우리 아기 D-day` 선택
   - **When Interacting** → `Run Script` (이래야 눌렀을 때 앱이 열립니다)
7. 빈 곳 아무데나 눌러 완료

---

## 크기별로 이렇게 나옵니다

| 위젯 크기 | 숫자 크기 | 보이는 내용 |
|---|---|---|
| Small | 56pt | 이름 · D-day · 주수 |
| Medium | 78pt | + 남은 일수 · 예정일 |
| **Large** | **128pt** | + 진행 막대 |
| **Extra Large** (아이패드) | **190pt** | 전부, 제일 시원함 |
| 잠금화면 | 30pt | 이름 · D-day · 주수 (크기 고정) |

## 자주 묻는 것

**Q. 숫자가 안 바뀌어요**
iOS가 위젯을 몇 분~몇십 분 간격으로 갱신합니다. 바로 보려면 위젯을 한 번 누르거나,
Scriptable 앱에서 ▶︎ 로 실행해보세요. 날짜는 **자정 기준**이라 하루 지나면 정확히 1 줄어듭니다.

**Q. 인터넷이 없어도 되나요**
네. 날짜 계산만 하므로 **비행기 모드에서도** 작동합니다.

**Q. 위젯이 앱 데이터를 가져오나요**
아니요. 위젯은 로그인을 할 수 없어서 서버의 아기 정보를 읽지 못합니다
(가족 사진을 지키는 보안 설정 때문이고, 정상입니다).
그래서 날짜를 코드에 직접 적습니다. 앱에서 출산예정일을 바꾸셨다면
위젯 코드도 같이 고쳐주세요.

**Q. 가족마다 다른 아기를 띄울 수 있나요**
네. 각자 자기 폰에서 **3단계**의 이름·날짜만 자기 아기로 바꾸면 됩니다.
서로 영향 없습니다.

**Q. 더 크게 보고 싶어요**
위젯 말고 **전체화면 페이지**를 쓰세요:
`https://scott910512-source.github.io/toto/dday.html`
Safari로 열고 **공유 → 홈 화면에 추가** 하면 주소창 없이 화면 전체를 D-day가 채웁니다.
아이패드를 세워두는 용도로 좋습니다 (화면도 안 꺼집니다).

**Q. 안드로이드도 되나요**
Scriptable은 iOS 전용입니다. 안드로이드는 위 **전체화면 페이지**를 쓰시거나,
크롬에서 열고 **홈 화면에 추가** 하세요.
