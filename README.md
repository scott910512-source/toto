# 🍱 올리브식권 간편식 신청 도우미

올리브식권 **사전구매(간편식)** 를 **요일별 · 끼니별(아침/점심/저녁)** 로 설정해 두고,
날짜 범위를 지정하면 그 기간의 **신청 계획표**를 자동으로 만들어 주는 웹앱입니다.
설치나 빌드 없이 브라우저에서 바로 동작합니다.

## 기능
- **① 신청 기간**: 시작일~종료일 지정 (이번 주 / 다음 주 / 이번 달 / 앞으로 14일 빠른 선택)
- **② 요일별 · 끼니별 설정**: 월~일 각 요일마다 아침/점심/저녁을 **체크**하고,
  **목록선택바(드롭다운)** 에서 메뉴를 고릅니다. → 여기서 정한 내용이 기간 내 매주 같은 요일에 반복 적용
- **📋 신청 계획표 만들기**: 날짜별로 "무슨 끼니에 무슨 메뉴를 신청할지" 표로 정리 → **📑 복사**로 한 번에 복사
- **💾 설정 저장**: 설정과 기간을 이 브라우저(localStorage)에 저장 → 다음에 열면 그대로 복원
- **🍱 메뉴 관리**: 목록선택바에 나오는 간편식 메뉴를 직접 편집(`그룹명: 항목1, 항목2` 형식)

## ⚠️ "완전 자동신청"에 대한 솔직한 안내
올리브식권은 **모바일 전용 앱**(㈜이라이즈, `com.erise.cybermealticket`)이고, 공개된 웹 주문
페이지나 공개 API가 없습니다. 그래서 **웹페이지에서 올리브식권 서버로 신청을 직접 전송하는
완전 무인 자동화는 이 앱만으로는 불가능**합니다(로그인 토큰·CORS·앱 전용 API 문제).

이 도우미가 하는 일은 **신청할 내용을 미리 한 번에 설계·정리**해 주는 것입니다. 실제 "전송"까지
자동화하려면 다음 단계가 필요합니다(접속 방식이 확정되면 진행):

| 방식 | 설명 | 난이도/안정성 |
|------|------|----------------|
| 손으로 입력 | 이 계획표를 보고 앱에서 그대로 신청 | 가장 쉬움 / 안정적 |
| 안드로이드 매크로 | Tasker·MacroDroid 접근성 매크로로 탭/입력 자동화 | 중간 / 앱 UI 바뀌면 깨짐 |
| 앱 API 분석 | 앱의 비공식 API를 분석해 직접 호출 | 어려움 / 약관·안정성 이슈 |

## 메뉴 채우기
`data.js` 의 `OLIVE_MENU` 가 목록선택바의 기본 메뉴입니다(현재는 예시 메뉴).
실제 올리브식권 간편식 메뉴 이름을 알게 되면:
- **앱에서**: 🍱 메뉴 관리 패널에서 편집 후 "메뉴 적용" (이 브라우저에 저장)
- **코드에서**: `data.js` 의 `OLIVE_MENU` 값을 바꾸기 (모든 기기에 반영)

```js
window.OLIVE_MENU = [
  { group: "도시락", items: ["제육 도시락", "치킨마요 도시락"] },
  { group: "음료",   items: ["흰우유", "아메리카노"] },
];
```

## 실행 방법
별도 서버가 필요 없습니다.
1. **로컬 PC**: `index.html` 더블클릭해 브라우저로 열기
2. **휴대폰/태블릿**: GitHub Pages로 배포해 웹 주소로 접속

### GitHub Pages 배포
1. GitHub 저장소 → **Settings** → **Pages**
2. *Source* 를 `Deploy from a branch`
3. Branch 를 `claude/olive-meal-automation-Sa0Gy`(또는 병합 후 `main`), 폴더는 `/ (root)` → **Save**
4. 표시되는 `https://<사용자명>.github.io/toto/` 주소로 접속

## 파일 구성
| 파일 | 설명 |
|------|------|
| `index.html` | 화면 구조 |
| `style.css` | 스타일 |
| `app.js` | 설정·계획표 생성 로직 |
| `data.js` | 간편식 메뉴 · 요일 · 끼니 정의 |

> 참고: `config.js` 와 `worker/` 폴더는 예전 앱의 흔적이며 이 앱에서는 사용하지 않습니다.
